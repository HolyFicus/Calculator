# Умный калькулятор студенческих оценок

Калькулятор студенческих оценок с математическим прогнозом, гибкой шкалой баллов, AI-советником и шаблонами учебных дисциплин.

🌐 **Официальный сайт на GitHub Pages:**  
https://holyficus.github.io/Calculator/

---

## 🚀 Как запустить или развернуть на GitHub Pages

### Автоматическое развёртывание через GitHub Actions (уже настроено)
В репозитории создан файл `.github/workflows/deploy.yml`. 

Чтобы включить GitHub Pages в репозитории:
1. Откройте репозиторий [https://github.com/holyficus/Calculator](https://github.com/holyficus/Calculator).
2. Перейдите во вкладку **Settings** (Настройки) → слева раздел **Pages**.
3. В выпадающем списке **Build and deployment** > **Source** выберите **GitHub Actions**.
4. После пуша в ветку `main` сайт автоматически соберется и станет доступен по адресу:
   👉 **https://holyficus.github.io/Calculator/**

## 🛠️ Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка статической версии для продакшена
npm run build
```

## 📋 Возможности приложения:
* **Индивидуальные шкалы оценивания**: 5-балльная, 10-балльная (НИУ ВШЭ), ECTS (A-F), Зачёт/Незачёт.
* **Математический расчёт автомата и целевой оценки**: точный расчёт оставшихся баллов и процентов.
* **AI-советник (Gemini)**: стратегия подготовки и анализ рисков.
* **Шаблоны дисциплин**: обмен готовыми учебными планами с одногруппниками по короткому коду.
